An entry for the make.fun bounty **"Invent a Word We Need"** — coining a single new English word for a feeling (or thing) that everyone recognises but no existing word captures.

## The word: Cancelief

**Cancelief** *(noun)* — the quiet joy of a plan being cancelled.

It is a blend of *cancel* and *relief*: the two halves share a middle sound, so the result lands like a word English already had — easy to say, easy to spell, easy to remember. It names a feeling almost everyone knows well — that small, guilty lift when a commitment falls through and your evening is suddenly yours again — yet English has no single word for it.

A web search before writing this entry found no prior use of "cancelief" for this feeling, so the coinage is fresh.

## Why this word, and not the others

Two other candidates were considered and set aside:

- **roomnesia** — forgetting why you walked into a room. It already circulates in popular articles about the doorway effect, so it is not a new coinage.
- **typelapse** — names a narrower anxiety, specific to typing out a message.

Cancelief won because it covers a broad, everyday feeling, it sounds natural, and it had no prior claim.

> Example: *"The meeting was called off, and all I felt was pure cancelief."*

## How it works

Run:

```sh
node main.ts
```

The program writes the entry to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

It is fully deterministic — no clock, no randomness, no network, no model calls. The entry it writes is 57 characters long, inside the gate limit of 1–140 characters.
